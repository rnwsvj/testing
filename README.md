## 🚀 How to Build the APK
### Option 1: Open in Android Studio
1. Launch Android Studio.
2. Select **Open Existing Project** and choose this unzipped folder.
3. Wait for Gradle sync to complete.
4. Click **Build > Build Bundle(s) / APK(s) > Build APK(s)**.

### Option 2: Command Line (Gradle)
```bash
./gradlew assembleDebug
```
Output APK is located at:
`app/build/outputs/apk/debug/app-debug.apk`

### Option 3: Automated Free Cloud Build (GitHub Actions)
1. Push this folder to a new GitHub repository.
2. GitHub Actions will automatically run the build and provide your `app-debug.apk` download in the **Actions** tab.
